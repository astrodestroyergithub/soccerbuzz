# Soccerbuzz — The Football Equivalent of Cricbuzz

**Cricket : Cricbuzz :: Football : Soccerbuzz**

Soccerbuzz is a responsive, zero-dependency, Netlify-ready football live match center, minute-by-minute commentary engine, 2D tactical pitch visualizer, standings & knockout bracket predictor, stats radar, and transfer newsroom covering:
- **FIFA World Cup 2026**
- **UEFA Champions League**
- **LaLiga**
- **Premier League**
- **Bundesliga**
- **UEFA Euro**
- **Serie A**
- **Indian Super League (ISL — including the Kolkata Derby)**

## Deploying to Netlify

1. **Drag & Drop Deploy**: Go to [app.netlify.com/drop](https://app.netlify.com/drop) and drag the unzipped `soccerbuzz` folder (or upload `soccerbuzz-netlify.zip`).
2. **Git / CLI Deploy**:
   ```bash
   npx netlify-cli deploy --dir=. --prod
   ```
